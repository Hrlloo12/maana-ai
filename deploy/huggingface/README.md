# مَعنى | MA'NA

منصة تقيس ما فهمه المتلقي فعلًا من المحتوى الإسلامي، وتتحقق بالقرآن الكريم وصحيحي البخاري ومسلم، وتعيد الشرح حتى يصل المعنى بأمانة.

The system calls the OpenAI API. The key is provided as the `LLM_API_KEY` secret of this Space and is never stored in the repository.

Sources: Qur'an text from [Tanzil.net](https://tanzil.net) (CC BY 3.0, verbatim); Sahih al-Bukhari and Sahih Muslim from [SENODROOM](https://github.com/SENODROOM) (AGPL-3.0), downloaded while the image is built.
